# Papyrus

A static homepage for hosting notes generated by Papyrus.
[Click here to start reading](https://itsamir-hs.github.io/papyrus)

## Features

- Grid of all notes with their titles
- Live search with highlighted matches
- Theme switcher (light, dark, forest, paperLike, neon) — synced with the notes
- Auto-generated manifest of all notes

## Structure

```
papyrus/
├── index.html          # Homepage
├── styles.css          # Themes + styles
├── app.js              # Search, theme switcher, note rendering
├── notes.json          # Manifest (auto-generated)
├── update-manifest.js  # Regenerates notes.json
└── note_<name>/        # Note folders
```

## Adding a new note

1. From the `papyrus/` directory, run:
   ```
   node update-manifest.js
   ```
2. Commit and push.

`update-manifest.js` scans all `note_*/output/index.html` files, extracts their `<title>`, and writes `notes.json`.
