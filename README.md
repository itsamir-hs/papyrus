# Papyrus

A static homepage for hosting notes generated by Papyrus.
[Click here to start reading](https://itsamir-hs.github.io/papyrus)

## Features

- Grid of all notes with their titles, grouped by category
- Live search with highlighted matches (matches note titles and category names)
- Theme switcher (light, dark, forest, paperLike, neon) — synced with the notes
- Auto-generated manifest of all notes

## Structure

```
papyrus/
├── index.html          # Homepage
├── styles.css          # Themes + styles
├── app.js              # Search, theme switcher, note rendering
├── notes.json          # Manifest (auto-generated)
├── update-manifest.js  # Regenerates notes.json
├── papyruswebicon.jpg  # Favicon + share-link image
├── note_<name>/        # Uncategorized note folders
└── cat_<category>/     # Category folders
    └── note_<name>/    # Notes inside a category
```

## Adding a new note

1. From the `papyrus/` directory, run:
   ```
   node update-manifest.js
   ```
2. Commit and push.

`update-manifest.js` scans `note_*/output/index.html` and `cat_*/<note folder>/output/index.html`, extracts each `<title>`, and writes `notes.json`.

## Categories

Create a folder named `cat_<categoryName>` and put note folders inside it:

```
cat_Immunology/
└── note_Immuno1/output/index.html
```

The site shows the name after `cat_` as the category heading (underscores become spaces, so `cat_Clinical_Lab` shows as "Clinical Lab"). Notes that sit directly in `papyrus/` as `note_*` are shown under "بدون دسته‌بندی".
