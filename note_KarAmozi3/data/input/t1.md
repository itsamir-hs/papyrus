# سیستم عصبی

## مقدمه

سیستم عصبی یکی از مهم‌ترین سیستم‌های بدن است و وظیفه‌ی
دریافت، پردازش و انتقال اطلاعات را بر عهده دارد.

در این جزوه از اصطلاحات **Central Nervous System** و
**Peripheral Nervous System** استفاده می‌شود.

### اجزای اصلی

- مغز
- نخاع
- اعصاب محیطی

### یک مثال ریاضی

رابطه‌ی معروف انرژی اینشتین به صورت زیر نوشته می‌شود:

$$
E = mc^2
$$

و یک فرمول داخل متن نیز داریم: $x^2 + y^2 = z^2$

### جدول

| مفهوم | توضیح |
|---|---|
| CNS | سیستم عصبی مرکزی |
| PNS | سیستم عصبی محیطی |
| Neuron | سلول عصبی |

> **نکته:** نورون‌ها واحدهای اصلی سیستم عصبی هستند.

def calculateEnergy(mass, speedOfLight):
